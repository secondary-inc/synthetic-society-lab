## Resource and lifecycle semantics

The new ledger persists immutable design/source/parent provenance and replays deterministic transitions against fixed work descriptors. It derives counters from reservations/terminal proofs rather than mutable totals/copies. The source bytes count once as unique/retained even though local GET/BODY/network use is0; this never refunds old GET/old C charges. External actual cache bytes are included in logical retained storage. Every source enrollment/parse/finalization reservation precedes its worker; native cumulative/per-state/per-sweep/time/memory/storage/free-space bounds remain independent.

ENROLL reserves native6,356,992expanded bytes and300seconds. Successful proof reduces only unused proven allowance. Parse reserves exact expected rows/person-plus-two-auxiliary expansion and300seconds per sweep. Each FINALIZE reserves6million logical units and300seconds; both finalization times count once, with no51-state union reservation or double counting, against the same3,600second processing cap. Failed/unknown work retains full reservations, including all mandatory ops. There is no success/replay/cache operation refund. Semantic proof caching validates a state-part hash once per opened ledger while still checking its exact file hash on every reuse; it changes no experimental reservation.

Torn event/state writes refuse with no reinitialization. A separate run marker and retained-stage checks also refuse lost state/ledger or marker deletion rather than creating a new zero-use ledger. A clean durable pending reservation can be explicitly recovered UNKNOWN without rerunning/refunding. Structured failures contain stage/type only; actual failures report unknown processed-row count rather than inventing0. Source failure and permanent analysis failure are separate. Authored source continuation requires the exact current state/design and preserved charges, cannot retry a consumed key and does not clear analysis barriers. Actual source continuation is unavailable pending its separately reviewed authority; no blanket national source shutdown or new policy is inferred. Analysis FAILED/UNKNOWN blocks a different future finalization before reservation/worker dispatch. This is the accepted trusted execution/preserved-history boundary, not hostile rewriting of all authority/history or cryptographic authentication.

POSIX child supervision records successful sampled RSS/time and terminates on sampled threshold/deadline/cancellation. It is not an absolute OS/wire/physical-block guarantee. Proof validation/serialization/hash I/O consumes elapsed/local resources; logical reference-operation units are not CPU instruction counts. The fixture has78 authored all-age rows, not actual29,297-row or national-volume validation. Larger actual input compatibility, resource consumption and source precision remain unverified.
