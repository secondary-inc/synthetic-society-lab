# E02 support-model comparison

This is a retrospective exploratory comparison on the already-inspected ANES survey holdout. It preserves the original six-field coarsened distribution target and the original sparse-suppression fit; no population milestone is certified. Plan: `configs/e02_population_support_plan.json`, written before the candidate metrics. It is not externally preregistered.

Run with `PYTHONPATH=src .venv/bin/python -m civiclab.e02.population_alternatives`. The runner first verifies the same registered input bytes through the original population fitter, then independently reproduces its sample rules and cluster split. It fails if retained-plus-suppressed training counts or held-out counts disagree. Internally, survey records and cluster identifiers are used for fitting and resampling; only aggregate diagnostics, source hashes and the plan enter recorded run artifacts.

The common evaluation grid contains 2,880 region × age × education × party × race × income cells. Both new models retain all 2,286 eligible training records and their survey weight, including the 1,033 records suppressed by the original fit. The simpler model multiplies smoothed global marginal probabilities. The hierarchical model estimates the region-age-education joint distribution, conditional party, and conditional joint race-income with parent-node smoothing. Training weights are normalized to record count before adding prior-record pseudo-counts, preventing the arbitrary weight normalization from choosing the smoothing strength. Primary prior strength is fixed at five, with one and twenty reported only as sensitivities.

All three models use the same resident ACS regional age and education calibration and the same 446 held-out weighted records. Every model is scored using the same small uniform floor, q=(1−epsilon)p+epsilon/2880, epsilon=1e−9. This makes zero-support log loss finite; raw support coverage is reported separately. The floor materially affects the suppressed model's absolute score, so that figure should not be generalized independently of the declared scoring rule. Full support in smoothed models is imposed, not evidence of representativeness. The resampling interval uniformly resamples the 352 held-out survey clusters using paired weighted losses; it is descriptive, not a complete survey-design variance estimator.

Primary tau=5 results: independent weighted log loss 6.93936 nats, hierarchical 7.16178 nats. The hierarchical-minus-independent difference is +0.22242 nats, with descriptive paired cluster bootstrap interval [0.05118, 0.41953]. Lower loss is better. Thus this candidate hierarchical configuration has not earned promotion over its simpler comparator. The original suppression model has 19.62295 nats under the declared scoring floor, retains 47.7978% of eligible training survey weight and covers 38.7408% of held-out survey weight. Both smoothed candidates retain 100% training weight and assign positive probability to the full grid by construction. No best-tau selection is performed: tau=1 and tau=20 remain sensitivity results, including unfavorable results.

The original representative-population gate remains BLOCKED. The same holdout has already informed diagnostics, ACS benchmarks describe residents while the ANES target is citizens, state-level inference is unsupported, and neither generator validates political responses against humans. Do not substitute this model into frozen pilots or declare demographic complexity earned without a separate amendment and independent review.

## Citizenship benchmark investigation

Official 2024 ACS subject group S0501 provides metadata for Native (C02) and Foreign-born; Naturalized citizen (C04). Total population and educational population 25+ variables are integer estimates; age and education subgroup estimates have float metadata and may be percentages. Correct conversion requires verifying table units/denominators and propagating published rounding. Those steps have not been completed, and no citizen margins have been fabricated.

The official group metadata URL is `https://api.census.gov/data/2024/acs/acs5/subject/groups/S0501.json`. A keyless state-data request to the documented subject endpoint returned an HTML “Missing Key” page rather than JSON data. Metadata and the failed response remain in ignored `data/raw/e02_citizen_benchmarks/` with their hashes in the evidence receipt. No credentials were supplied or access controls bypassed. This observed API failure does not prove all permitted Census download channels are unavailable. A normal official table download or a properly provisioned Census key remains a possible next acquisition route; neither is represented as successful here. Citizen/resident alignment remains unresolved, and the active calibration remains unchanged.
