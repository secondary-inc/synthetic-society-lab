# E02 citizen25+ target conversion v1

This stage implements only the independently approved methods proposal in `docs/E02_CITIZEN_FIT_PROPOSAL.md`, with its exact hash and review/source hashes pinned in `configs/e02_citizen_targets_v1.json`. It creates derived approximate calibration targets for arithmetic review. It does not fit any population, select a model, authorize live inference or open a scientific gate.

Run `PYTHONPATH=src .venv/bin/python -m civiclab.e02.citizen_targets`. Outputs go to a new immutable E02 EXPLORATORY run under ignored `data/processed/runs/`. The run stores the versioned config, full `citizen-targets.json`, source/proposal/audit/config/implementation hashes, code identity, environment, events and checksum ledger. Required source/review byte changes fail closed. Each invocation creates a new run; previous runs are never overwritten. Failed configurations retain run manifests and failure events; arithmetic failures also retain a target-conversion error artifact identifying the state/column. Input errors propagate to the caller and cannot be mislabeled a completed target diagnostic.

The converter verifies the acquired ZIP and original metadata before using its52 geography records. Puerto Rico remains in the source and is explicitly excluded from these51 state/DC targets. For each state and each disjoint C02 Native / C04 Foreign-born Naturalized citizen column, the artifact records raw source estimates, units, original90% MOEs, proposed percentage denominators, raw approximate counts, published25+ anchor, normalization scale, normalized approximate counts, rounding-only componentwise share/count bounds and consistency diagnostics. Native+naturalized published25+ totals and normalized age/education counts are aggregated to the same four-region/national mass. No raw respondent records are used or exported by this converter.

Decimal arithmetic uses40 significant digits; Decimal values are serialized as decimal strings. Published integer source counts remain integer estimates; the normalized subgroup counts are derived approximate values, not published exact counts. Per-cell rounding intervals are not simultaneous feasible target vectors or90% confidence intervals. The converter retains MOEs but estimates no covariance-adjusted benchmark uncertainty. The point targets are not activated in the original fitter or frozen comparison.

Tests: `PYTHONPATH=src .venv/bin/python -m unittest discover -s tests -p 'test_e02*.py' -v`. Six new test cases cover hand-calculated age/education denominators and coarsening; normalization and inconsistent rounding; exact geography and native/naturalized addition; invalid estimates, MOE annotations, mixed products, overlapping citizenship categories and swapped count definitions; immutable fixture replay; changed proposal and source bytes. All31 E02 tests passed at worker handoff. These tests establish bounded engineering behavior, not scientific acceptance.

The first real diagnostic uses51 states/DC ×2 citizenship columns. Published25+ totals sum to212,109,587: Northeast37,114,497; Midwest45,202,786; South81,487,874; West48,304,430. These are sums of acquired2020–2024 ACS five-year subgroup point estimates, not a2026 census. Observed age normalization scales range approximately0.997600..1.001972; education scales0.999001..1.002004. Source education percentage sums range99.8..100.1; the maximum raw age-derived versus published25+ discrepancy is about0.0019883 of the all-age column total, within the predeclared0.003 plus1-person bound. Full precision and all per-column diagnostics are stored in the target artifact. No inconvenient values were removed or silently coerced.
