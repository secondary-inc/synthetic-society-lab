## Exact logical schema and binary layout

Thus51×4×3×2×3=3,672 cells and293,760 signed replicate components are mandatory, even for unprocessed or released-zero cells. Each state has72domain cells.

Citizenship recode is CIT1–4/5; residence RELSHIPP20–36/37/38; education SCHL1–17/18–20/21–24. C is the CITIZEN/HOUSEHOLD slice:612cells. F's612age/education cells sum all six domains; they are derived views, not an additional population sample. No domain/state deletion is allowed for sparsity.

The config includes an exact logical primitive-cell JSON schema, required fields, enums, integer/null domains and80-element arrays. Each recorded cell holds unweighted count, point-weight sum, squared-point-weight sum,80 signed replicate sums, and unweighted/point-weight allocation totals for FAGEP/FCITP/FSCHLP/FRELSHIPP. Political-prior status is always `NOT_IDENTIFIED_BY_PUMS`; no political value is created for C or F by this benchmark.

Default physical storage is headerless little-endian two's-complement signed64 arrays with no padding: `count.i64le`, `point.i64le`, `sum_squared.i64le` each shape[3672]; `replicates.i64le` shape[3672,80]; `allocation_counts.i64le` and `allocation_weights.i64le` each[3672,4]. Source/support status masks are each3,672uint8 bytes. Shapes, exact lengths and axis order are normative in the config. Total primitive payload is2,680,560bytes, of which2,350,080bytes are replicate integers. This is storage arithmetic, not observed process RSS or serialized-artifact size.

Source mask0 means unprocessed: numeric slots must contain zero padding but the logical decoder MUST expose NULL, including all80replicates and allocation fields. Padding is not a measured zero. Source mask1 means validated: integers are exposed, including legitimate sample zeros. Support codes distinguish unknown source, no released contributors, source count below30 and recorded source support. A known count0 requires zero point/squared/replicate/allocation sums; positive count implies positive point sum. Allocation counts cannot exceed contributing count and allocation point weights cannot exceed point weight. The decoder validates these cross-field constraints in addition to the JSON schema. A processed sample zero does not establish a structural population zero. Count30 is a flag threshold, not scientific precision, anonymity or release permission.

## Precision and covariance scalability

Released weights are already five-year ready; no extra divide by five. Preserve negative/zero replicate inputs. All primitive sums use checked64-bit storage; a native arithmetic overflow must fail rather than wrap. Source-count/weight bounds fit the primitive types, but squared replicate deviations/cross-products can exceed64bits. Compute those numerators with arbitrary-precision integers and serialize canonical decimal strings. For count/linear-count covariance, denominator20 represents4/80 exactly. SE and MOE use finite float arithmetic, with MOE90=1.645SE and conditional-sampling limitations.

Retain point vector X and replicate matrix R. The count-covariance factor D=R−X, computed columnwise on the same replicate index, represents covariance D D-transpose /20 and rank<=80. A dense3,672² matrix has13,483,584entries and107,868,672float64 payload bytes before language/JSON overhead; naive80-replicate all-pairs computation exceeds a billion cross-products. Dense all-pairs creation/storage is refused before allocation by default. Diagonals, required aggregate totals and ratios are computed from corresponding replicate estimates. Any predeclared extra work is limited to4,096covariance pairs,128scalar contrasts and64million analysis multiply-adds across the batch. Raw record-weight accumulation is charged to source row/time resources rather than this query-only budget. Reserve worst-case analysis work before evaluation; no automatic all-pairs fallback or limit increase.

Required shares explicitly label their denominator: primitive/F-age-education cells use F_state; C-age-education cells use C_state; C's population coverage is C_state/F_state. Do not replace one denominator with another or present C-normalized scores as full-adult scores. Recompute each replicate numerator/denominator first. A missing or nonpositive point denominator, or any missing/nonpositive replicate denominator, yields NULL uncertainty with a typed blocked reason. Signed replicate shares outside0..1 are not clipped. Point/sampling-zero cases retain review flags rather than false certainty; no unreviewed GVF/design-factor fallback or total-error/human-validity interval is emitted. The config freezes uncertainty-record fields/statuses, numerator/denominator references, exact decimal count-variance numerator and denominator20. A valid point estimate may remain when only its replicate denominators fail; variance/SE/MOE are NULL. Missing/nonpositive point denominator also makes the point NULL. No partial-replicate variance is substituted. Ratio calculations use finite float64 with independent-oracle acceptance tolerances absolute1e−12/relative1e−9; exact integer identities/count-SDR numerators require equality.
