## One-parent recording and recovery semantics

`alabama_recorded_preflight_v1.record(root, raw, expected_sha=..., phase=...)` requires full release metadata admission before controls/RunStore/source reads. Each recorded phase has one manually managed parent and no child success. Reader admission requires exact files (no extra nested directories), checksum/payload hashes, manifest/summary/commit/seal bindings, absence of failure markers and equality to input-derived private/public/provenance data. Read-only saved validation rechecks every pinned base metadata and all three grant documents plus transcript/audit semantics without PDF/image reads or source parsing. Primary/replay private and public data bytes match; provenance intentionally records its distinct phase.

Errors, parser/hash/persistence faults, KeyboardInterrupt and SystemExit preserve type/static-only evidence. Partial files stay local.
