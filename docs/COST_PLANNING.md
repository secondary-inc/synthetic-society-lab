# Review-only experimental call costing

`civiclab cost-plan --spec PATH --out PATH` computes conservative aggregate reservations for an exact frozen list of text calls. It never loads credentials, contacts a provider, reserves funds or enables execution. The output always states `dispatch_authorized: false` and retains the default disabled, zero-cap policy.

The JSON input has `schema_version: 1`, a `price` object with the same fields as `civiclab.model.Price`, and a nonempty `calls` array. Every call contains exactly `module` (E01/E02), `messages` (role/content objects) and `max_tokens` (1–4096). All calls in one specification use that exact model/provider price. Split model/provider variants into separate plans, then sum their ceilings for the full proposal. An unfilled or stale price is a blocker; no current experimental model or price is invented here.

The planner and actual OpenRouter adapter share `call_envelope()`: UTF-8 serialized message bytes plus 1,024 framing tokens per message, with the same 100,000-byte and output ceilings. It prices the conservative envelope, rounds each individual reservation upward to a microdollar exactly as the ledger does, then sums by module and over the full plan. Summing costs before rounding could understate a large batch's required cap. This is a cap requirement, not expected billed usage.

Only message hashes, byte/token bounds and reservation amounts are exported, rather than message content. This cost specification does not freeze seeds, temperature, assignment or the full experimental request schema; the reviewed study plan must bind those separately. Adaptive post-survey requests cannot be presented as an exact frozen list before their baseline answers exist. A reviewed schema-based upper envelope or separately gated staged plan is required for those requests; this command does not invent their unknown answers.

Price validation establishes supported formatting, positive rates, an official OpenRouter URL and freshness. It does not independently authenticate a supplied rate. Before any execution, independent source evidence must verify exact provider pricing, applicable fees and capabilities. The owner must separately authorize positive caps; exposed credentials must be rotated and securely validated; research inputs, population, protocol and stimulus gates remain required. No cost plan opens those gates or derives a scientific sample size from deterministic mock variance.

The tests use conspicuously labeled fictional price/model/provider values with injected transports only. They verify per-call rounding against actual ledger reservations, uncertain-call accounting, UTF-8 bounds, stale-price rejection and malformed calls. They are not live billing or current-price evidence. No real priced execution proposal has been accepted or dispatched.
